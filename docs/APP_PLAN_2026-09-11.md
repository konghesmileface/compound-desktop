# 复利 App 立项文档(2026-09-11 拍板版)

> 本文档是 app 开发的单一入口。新 session 开工前先读完本文,再读 SESSION_HANDOFF_2026-09-11.md 了解桌面端现状。
> 拍板人: 机主。拍板方式: 与 Claude 多轮讨论后逐项确认。

## 一、产品定位(为什么做 app)

**app 不是桌面端的缩小版,是"大脑的采集器 + 提醒器"。**

- 桌面端 = 你去找大脑(重查询、重管理、重可视化)
- app = 大脑来找你(主动推送) + 随手喂它(万物入库) + 随时问一句(路上查人查事) + 沉浸消费(冥想听歌)

铁律不变: **客户电脑 = 服务器,数据不出本地**。app 不存业务数据,只是一块远程屏幕 + 一个采集口。

## 二、Tab 结构(5 个,已拍板)

| Tab | 形态 | 内容 |
|-----|------|------|
| 今日 | webview | 主动推送流: 承诺雷达到期提醒、见面前简报、今日新发现、供需撮合线索。推送通知点进来落这里 |
| 问 | webview | 统一问答入口,复用问大脑/问TA分流。典型场景: 见客户路上问"上次和他聊到哪了" |
| 收集 | **原生**(中间大按钮) | 拍照/相册截图/文件选择器/粘贴链接(公众号/网页/视频链接自动分流)。场外入口=分享扩展 |

## 三、Webview 策略(不走审核的关键)

- H5 全部托管在云端域名(compoundtome.com),页面是静态壳不含数据,加载后连桌面端 API 取数。UI 迭代随时发、零审核,隐私故事不破。
- 打一份离线兜底包进 app,断网/服务器挂了不白屏。
- **Apple 4.2 最小功能条款会拒纯 webview 壳**。原生面必须有: tab 骨架、收集(相机/文件/相册)、分享扩展、推送通知、后台音频(冥想锁屏播歌)。这五样恰好也是产品上该原生的,过审够用。

## 四、收集/导入实现(iOS 三个标准口子)

1. **分享扩展(Share Extension)——主力入口**。原生 Swift 小 target,注册接收 PDF/图片/链接/文本。微信文档"用其他应用打开"、Safari 分享、相册分享都会出现"复利"。收到后存 App Group 共享容器→上传。只首次上架过审,之后收到的东西怎么处理全在服务端/网页侧随时改。
2. **文件选择器**(UIDocumentPicker): iCloud/微信文件(存过的会出现在"文件"app)/WPS。
3. **相册选择器**(PHPicker): 批量截图/照片,走已有 OCR 管线。

链接入库分流:
- **公众号文章**: mp.weixin.qq.com 公开网页,桌面端直接抓正文+图片入库。最好做。
- **普通网页**: 抓取 + readability 类正文提取。好做。
- **视频**: 本质=下载+ASR 转写(SenseVoice+sherpa-onnx,已调研)。B站/抖音可做但每平台一套解析且会被改版打坏; **微信视频号做不了**(无公开 URL,加密分发),明确不承诺。视频入库与通道/tab 工作解耦,排在所有确定项之后做。

## 五、连接通道(核心架构,一步到位版)

### 5.1 总原则

**能直连就直连(WebRTC 打洞),直连不成走中转(106 转发),用户全程无感、零配置。**
第一版就带全套。开发顺序仍是先中转后打洞——打洞的信令就是中转通道,是依赖关系不是阶段。

已否决路线(勿再提): Tailscale/VPN 组网(iOS 描述文件劝退+中国区商店禁 VPN)、用户开公网端口(不会配)、数据同步上云(破隐私入场券)。

### 5.2 架构

```
建连: 手机/桌面 各自向 STUN(106 coturn)照镜子拿外网地址
      经 106 信令(WS)交换地址 → ICE 同时互射打洞
打洞成功(~60-70%): 手机 <═ WebRTC DataChannel 直连 ═> 桌面,不过服务器
打洞失败:          手机 <══> 106 中转(WS 转发或 TURN) <══> 桌面
```

- 桌面端启动后**常驻一条外连 WebSocket 到 106**(走 443 穿一切 NAT): 既是中转数据通道,也是 WebRTC 信令通道,也是"可被叫醒"的存在证明。
- 106 部署: WS 中转服务(按账号路由+心跳+重连,几百行) + coturn(STUN+TURN)。

### 5.3 端到端加密(产品级卖点)

- 配对: 手机扫桌面端屏幕二维码交换密钥,**密钥不经过服务器**。
- 所有业务载荷应用层加密后才进通道(无论直连还是中转)。106 只见"谁发给谁多少字节"。
- 官网话术: "连我们自己的服务器都看不懂你的数据"。
- 注意: WebRTC 的 DTLS 只是传输层加密,应用层加密两条传输统一保留,协议一致。

### 5.4 传输无关协议层(先做这个)

定义"请求/响应帧 + 端到端加密封包"协议,webview 里 fetch 全走这层封包(桌面端已有 api.js fetch 影子经验,`window.__COMPOUND_API_BASE__` 同款思路)。封包底下可插三种传输: 局域网直连 HTTP(同 WiFi 自动探测,壳里做)/ WebRTC DataChannel / 106 WS 中转。上层页面对传输零感知。

### 5.5 WebRTC 实现选型(已定,防打包深坑)

- **WebRTC 不进 Python**。桌面端用 Tauri Rust 层(webrtc crate,静态编译零打包负担),桥接 localhost FastAPI; 手机端用 WKWebView 浏览器原生 WebRTC API(iOS 14.3+,零原生代码)。
- 理由: PyInstaller 上 aiortc 要带 pyav/ffmpeg 依赖链,以 paddle/numpy 九层打包坑的教训,坚决不碰。

### 5.6 大文件走 OSS 加密中转站

手机传照片/文档: 本地加密 → 传 OSS 临时地址 → 通知桌面端 → 下载解密入库后删除。
- 106 中转通道只承载文本(近零成本),文件流量走 OSS(便宜可扩)。
- 顺带解决**桌面端离线**: 文件在 OSS 排队,桌面端开机自动收。手机端显示"已收集,将在你的大脑上线后入库"。

### 5.7 桌面端离线的产品语言

问答类(问TA/雷达)桌面端不在线就是答不了,**不用云端缓存去糊**(糊了破隐私承诺)。手机端明示"你的大脑离线中,收集照常,问答等它上线"; 桌面端引导开机自启、接电源保持唤醒。强化"大脑住在你自己电脑里"心智。

## 六、壳与平台(2026-09-11 晚补充拍板)

- **iOS + Android 双端都做**(机主拍板)。壳选 **Capacitor**(webview 优先、一套代码双端出包、相机/推送/文件插件成熟);iOS 分享扩展仍需一个小 Swift target,Android 分享目标(intent-filter)原生即有。App 本体 80% 是 H5,壳越薄越好。
- **设计语言(机主拍板: 页面/图标/交互都要非常优秀、科幻,交互更要科幻)**: 延续"星海黑底金核"审美——深空黑底(#05070d 系)、金核+青辉双 accent、玻璃拟态面板、辉光描边、粒子星野背景、页面切换与加载用流光/星尘微动效。图标全 SVG 几何线条(全站禁 emoji 铁律)。手机 H5 独立设计系统,不复用桌面样式,单手操作优先。
- **账号流程齐全**: 注册(短信/密码,走 106 /account/register,送10天试用)、登录(/account/login)、忘记密码、账户基本资料(昵称/头像等,复用 profile API)。登录后引导扫码配对桌面端。
- **会员与订阅: app 只展示状态(tier/到期日/试用剩余),不做任何支付**(机主拍板: 付费留在桌面客户端完成)。注意 Apple 反引导条款——app 内不出现"去电脑购买"类文案和链接,只显示状态与到期提醒。
- 推送: APNs,由 106 触发(桌面端产生提醒→经 106 发推送; 推送正文注意别带敏感内容,只带"你有 1 条承诺到期"级别的提示,详情点进 app 经加密通道取)。
- 合规红线: **app 内不卖会员、不放购买链接**(IAP 抽三成),"我的"只显示会员状态,购买留官网。

## 七、开发顺序(一次发布,内部里程碑)

1. **M1 通道**: 协议封包层 + 106 WS 中转 + 桌面端外连模块 + 扫码配对加密 + 局域网直连探测。通了以后一切页面工作才有意义。
2. **M2 打洞**: coturn 部署 + Rust webrtc(桌面) + WKWebView WebRTC(手机) + 传输自动切换/回落。真机联调要覆盖: 家宽WiFi↔蜂窝、双蜂窝、公司网络、WiFi/蜂窝切换重连、iOS 切后台恢复。
3. **M3 壳与收集**: Swift 壳 5 tab + 相机/相册/文件 + 分享扩展 + OSS 中转站 + 推送。
4. **M4 H5 适配**: 今日(推送流,新页)/问/冥想(后台音频)/我的 移动端适配,托管上 compoundtome.com + 离线兜底包。
5. **M5 链接入库**: 公众号/网页抓取解析管线(桌面端)。
6. **提审**: 一次带全原生面过审。视频 ASR(B站/抖音)排在提审后,不阻塞上架。

## 八、明确不做清单

微信视频号入库 / VPN 组网 / 云端存业务数据 / app 内售卖 / 大画布可视化进 app / 云端缓存代答。
